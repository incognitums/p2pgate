# p2pgate v1.13.8

Code-quality release. No protocol or configuration changes; the only visible difference is
that host/target/status lists sort with the correct locale comparator.

## Fixed

- `.sort()` without a comparator in `hosts list`, `config-tools` and `status` — replaced
  with `localeCompare` / a numeric comparator
- duplicate `all` option in `src/cli.js`
- `device-registry` no longer uses a trailing-newline regex (avoids backtracking)
- `scripts/check-release.js` regex tightened (no super-linear backtracking)
- `src/mux.js` uses `Math.trunc` instead of `| 0`
- `scripts/soak/mux-termux.sh` uses `[[ ... ]]`
- committed `spike/mux/Cargo.lock` for reproducible builds

## Changed

- `// NOSONAR` annotations with justifications where SonarCloud flagged by-design paths
  or test fixtures. SonarCloud went from **35 open issues to 0** (Security A, Reliability
  A, Maintainability A).
- release tooling: `scripts/check-release.js`, `scripts/release.js`, `RELEASING.md`, and
  the `release:check` / `release:preflight` / `release:after` npm scripts
- `prepublishOnly` now runs `npm test` plus the release check

## Upgrading

```sh
npm i -g p2pgate@1.13.8
```

No config changes are required.
